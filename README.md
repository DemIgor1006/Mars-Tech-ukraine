# MARS TECH UKRAINE

Сайт-каталог світлотехніки MARS TECH та AYFAR від офіційного дистриб'ютора в Україні — ТОВ «ПЛА-ТАН І К».

## Структура

| Файл / папка | Що це |
|---|---|
| `index.html` | Увесь сайт: дизайн (CSS), сторінки й логіка (JavaScript) |
| `data/catalog.json` | 2 187 позицій: код, назва, OEM, категорія, марки/моделі, ящична норма, сертифікат. Без цін заводу |
| `data/img/i00.json … i16.json` | Фото товарів (WebP), по 80 у файлі, вантажаться при прокрутці |
| `img/mars-tech-logo.png` | Логотип MARS TECH (використовується з дозволу MARS) |
| `tools/build_catalog.py` | Скрипт, що збирає `data/` з бази «Довідник MARS · AYFAR» |

## Що можна змінювати вручну

- **Контакти, телефон, Viber, Telegram, e-mail, адреси, графік** — об'єкт `CONFIG` на початку `<script>` в `index.html`.
- **Тексти сторінок** (головна, MARS TECH, AYFAR, дилерам, контакти) — функції `viewHome`, `viewMars`, `viewAyfar`, `viewDealers`, `viewContacts` в `index.html`.
- **Кольори й шрифти** — блок `:root { ... }` на початку `<style>`.

`data/catalog.json` вручну краще не редагувати — перезбирайте через `tools/build_catalog.py`.

## Як відкрити в редакторі

На сторінці репозиторію натисніть клавішу **.** (крапка) — відкриється редактор github.dev просто в браузері.

## Як опублікувати сайт (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save.
Через 1–2 хвилини сайт буде доступний за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.
Власний домен (наприклад, marstech.com.ua) підключається там же, у полі Custom domain.

## Замовлення

Зараз форма формує текст замовлення (з округленням до ящичної норми для передзамовлення), який клієнт копіює або надсилає в Telegram. Автоматична відправка замовлень (Telegram-бот, e-mail, KeyCRM) — наступний крок.
